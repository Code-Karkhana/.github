# 🛠️ Welcome to Code Karkhana 

**Crafting code and chaos. Byte by byte.**

Code Karkhana (Code Workshop) is a collaborative research and development initiative created by university students. Our mission is to build robust, foundational software from scratch, targeting final year projects and tech expos, while strictly adhering to modern software engineering standards.

## ⚠️️ Our Core Ethos (The Standard)

We believe in learning by doing. To ensure we actually understand what we build, all contributors in this organization adhere to the following rules:

- 🚫 **Zero AI-Generated Code:** We do our own research, read the documentation, and write our code line-by-line. (AI is for explaining concepts, not writing the logic).
- 💬 **Code Clarity:** Proper commenting and clean code architecture are mandatory.
- 📚 **Research-Driven:** Every repository must maintain professional-grade documentation. Our ultimate goal is to publish academic research based on these projects.
- ⚙️ **Automation First:** We implement CI/CD, auto-builds, and GitHub Actions wherever possible.

## 🚀 Current Initiatives

*   🎮 **[Aether2D]** - A custom-built 2D game engine developed in C++ focused on rendering loops, entity mechanics, and physics without relying on pre-built commercial engines.
*   🛡️ **[Cybersecurity Simulation]** - Advanced research and simulation tools focusing on Web Application Firewalls (WAF) and DDoS mitigation strategies.
